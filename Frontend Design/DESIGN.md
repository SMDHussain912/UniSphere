## Brand & Style

This design system expresses a high-density, multi-sided ecosystem where education, code provenance, academic credentials, and career velocity converge. The interface language balances four key influences:
- **Linear's kinetic velocity:** Sharp hairline borders, micro-interactions, dark-mode-first structural contrast, and strict information-dense layouts.
- **Notion's editorial quietude:** Measured typography, generous interior line heights, and muted, non-distracting neutral surfaces.
- **GitHub’s developer precision:** Monospaced metadata blocks, semantic visual status chips, deterministic component states, and clear boundary markers.
- **Contemporary AI clarity:** Luminescent accent edges, contextual intelligence drawers, and purposeful gradient accents used strictly for high-impact actions.

The tone is authoritative, frictionless, and deeply focused. It rejects decorative bloat, loud marketing gradients, and heavy drop shadows in favor of systematic hierarchy, low-latency micro-details, and hairline-bound containers.

## Colors

The palette leverages a technical spectrum designed for dense visual telemetry across role views (learners, developers, educators, recruiters).

- **Primary (`#4338CA` / `#4F46E5`):** Deep electric violet used for dominant actions, primary navigational anchors, active workspace tabs, and key structural highlights.
- **Secondary (`#2563EB` / `#3B82F6`):** Precision azure blue applied to links, developer pipeline states, workflow nodes, and progressive disclosure indicators.
- **Tertiary / Accent (`#0D9488` / `#06B6D4`):** Vibrant teal and emerald cyan reserved for verification marks, skill proficiency indicators, code execution passes, and AI-assisted insights.
- **Neutral Palette (`#0F172A` Slate Core):**
  - **Canvas Base:** `#F8FAFC` (Canvas light), shifting to `#F1F5F9` for inset sub-panels and metadata sidebars.
  - **Surfaces:** Pure crisp `#FFFFFF` for elevated interactive cards, dropdown menus, and editor panes.
  - **Hairline Borders:** `#E2E8F0` for default containment; `#CBD5E1` for hover and focused boundaries.
  - **Text Layers:** `#0F172A` (Slate 900) for primary headings; `#475569` (Slate 600) for structural copy; `#94A3B8` (Slate 400) for secondary metadata, keyboard shortcuts, and disabled states.

## Typography

The type hierarchy pairs **Plus Jakarta Sans** for crisp, structural sectioning with **Inter** for data readability across high-density tables, IDE consoles, applicant tracking boards, and educational tracks.

- **Proportion & Tracking:** Headings use deliberate negative tracking (`-0.03em` to `-0.015em`) to evoke the precision of modern developer tools. Body levels use Inter's standard optical properties to maximize legibility across complex tables and compact lists.
- **Monospace Integration:** When rendering Git hashes, commit SHAs, terminal outputs, API endpoints, or test runner assertions, drop immediately to `code-inline` using JetBrains Mono at 12px.
- **Weight Restraint:** Limit weights strictly to 400 (regular body), 500 (interactive items and field entries), 600 (structural labels, subheadings, and titles), and 700 (primary display heroes). Never use thin, light, or extra-bold weights.

## Layout & Spacing

The layout philosophy uses a **fluid-grid container structure** driven by an 8pt base grid with a 4pt micro-unit for compact control layouts.

- **Grid Architecture:** 
  - **Desktop (1200px+):** 12-column dynamic fluid layout with `1.5rem` (`24px`) gutters and max content boundary capped at `1440px`. Sidebars (workspace navigation, file trees, curriculum trees) sit at fixed widths of `240px` or `280px`, allowing central canvas panes to flex.
  - **Tablet (768px – 1199px):** 8-column layout with `1rem` (`16px`) gutters. Secondary panels collapse into overlay drawers or segmented tab strips.
  - **Mobile (< 768px):** 4-column layout with `1rem` margin boundaries. Primary control rows stack vertically or convert into horizontal swipe rails.
- **Rhythm & Density:**
  - Standard intra-component padding is compact (`space-sm` to `space-md`) to ensure high visible data density without visual clutter.
  - Section-to-section layout spacing follows `space-2xl` (`32px`) to `space-3xl` (`48px`) to allow natural breathing room between unrelated feature modules.

## Elevation & Depth

This design system favors **structural surface definition over heavy physical drop shadows**. Depth is constructed through 1px hairline borders, deliberate background tinting, and ultra-diffused atmospheric ambient shadows.

- **Level 0 (Base Canvas):** `#F8FAFC`. Zero elevation, zero shadows. Used for overall platform backdrop and structural framing.
- **Level 1 (Panels & Cards):** `#FFFFFF`. Bound by a 1px solid hairline border of `#E2E8F0`. Shadow: `0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
- **Level 2 (Hovered Cards & Interactive Controls):** `#FFFFFF`. Hairline border darkens to `#CBD5E1`. Shadow: `0 4px 12px -2px rgba(15, 23, 42, 0.06), 0 2px 4px -1px rgba(15, 23, 42, 0.03)`.
- **Level 3 (Dropdowns, Command Palettes, Popovers):** `#FFFFFF`. Border: 1px solid `#E2E8F0`. Shadow: `0 10px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.
- **Level 4 (Modal Dialogs & Floating Drawers):** `#FFFFFF` with backdrop overlay of `rgba(15, 23, 42, 0.4)` paired with `backdrop-filter: blur(4px)`. Shadow: `0 25px 50px -12px rgba(15, 23, 42, 0.16)`.

## Shapes

The shape system employs deliberate corner radii mapped directly to component scale:
- **Controls & Form Inputs (Height 32px – 40px):** `rounded` (`6px` / `0.375rem`) to maintain developer-tool crispness.
- **Cards, Panes & Data Containers:** `rounded-lg` (`10px` to `12px` / `0.625rem` to `0.75rem`) for modern framing that preserves visual separation.
- **Modals & Overlays:** `rounded-xl` (`16px` / `1rem`).
- **Pills & Badges:** Full radius (`9999px`) reserved strictly for status pills, identity chips, verification tags, and micro-counters.

## Components

### Buttons & Interactive Triggers
- **Primary:** Background `#4338CA`, foreground `#FFFFFF`, border `1px solid transparent`. Hover shifts to `#3730A3` with subtle ring-offset glow. Active compresses slightly (`transform: scale(0.98)`).
- **Secondary:** Background `#FFFFFF`, foreground `#0F172A`, border `1px solid #E2E8F0`. Hover shifts background to `#F8FAFC` with border `#CBD5E1`.
- **Ghost / Tertiary:** Background transparent, foreground `#475569`. Hover shifts background to `rgba(241, 245, 249, 0.75)` and foreground to `#0F172A`.
- **Destructive:** Background `#FEF2F2`, foreground `#DC2626`, border `1px solid #FEE2E2`. Hover shifts background to `#FEE2E2`.
- **Height & Sizing:** Primary actions default to 36px height with 12px horizontal padding for compact density.

### Badges & Status Chips
- Pill-shaped (`rounded-full`), 20px height, uppercase tracking `0.025em`, font size 11px, font weight 600.
- **Verified / Success:** `#F0FDFA` background, `#0D9488` text, border `1px solid rgba(13, 148, 136, 0.2)`.
- **In-Progress / Info:** `#EFF6FF` background, `#2563EB` text, border `1px solid rgba(37, 99, 235, 0.2)`.
- **Role Tag (Learner/Developer/Recruiter):** `#F5F3FF` background, `#4338CA` text, border `1px solid rgba(67, 56, 202, 0.15)`.

### Form Fields & Inputs
- **Base Input:** Background `#FFFFFF`, border `1px solid #E2E8F0`, corner radius 6px, height 36px, font size 14px, horizontal padding 10px.
- **Focus State:** Border changes to `#4338CA` accompanied by an ambient ring: `box-shadow: 0 0 0 3px rgba(67, 56, 202, 0.12)`. Outline is none.
- **Error State:** Border `#EF4444`, ring: `0 0 0 3px rgba(239, 68, 68, 0.12)`.
- **Trailing Metadata:** Monospace keyboard shortcut indicators (e.g., `⌘K`) rendered at 11px in `#94A3B8` within 18px rounded containers.

### Cards & Data Containers
- White `#FFFFFF` surface enclosed by a 1px solid border `#E2E8F0` and `rounded-lg` (10px–12px) perimeter.
- Header sections feature a continuous divider line (`border-b border-[#E2E8F0]`) separating title/action rows from data payloads.
- Inset meta bars use background `#F8FAFC` to establish visual hierarchy without adding layer depth.

### Checkboxes & Radios
- Size: 16px × 16px. Border: 1.5px solid `#CBD5E1`. Radius: 4px for checkboxes, full circle for radios.
- **Checked:** Background `#4338CA`, border `#4338CA`, white geometric SVG checkmark or radio dot inside. Focus ring: `0 0 0 2px rgba(67, 56, 202, 0.2)`.

### Lists & Data Tables
- Clean tabular layouts with zero vertical dividing borders. Rows are defined strictly by a 1px horizontal bottom border of `#F1F5F9`.
- Row height: 44px for compact tables, 56px for items containing sub-labels or developer avatars.
- Row hover: Smooth 100ms transition to background `#F8FAFC`.

### Ecosystem Specifics: Developer & Credential Cards
- **Code Provenance Snippets:** Embedded code tiles render with a 1px border `#E2E8F0`, `#F8FAFC` header bar displaying git branch and execution status, and `#0F172A` terminal background for syntax review.
- **Multi-Role Profile Switcher:** Segmented control with 4px inner padding, `#F1F5F9` track, and active white surface card with `0 1px 3px rgba(0,0,0,0.06)` elevation.
